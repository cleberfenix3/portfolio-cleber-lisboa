# Checklist de publicação

1. Confirmar e inserir o LinkedIn público, caso desejado.
2. Escolher domínio/URL final.
3. Com a URL final, adicionar `canonical`, `og:url`, `og:image` absoluta e `sitemap.xml`.
4. Executar `npm install && npm run build`.
5. Testar Home, Galáxia, Projetos, Trajetória, Sobre, Contato e P01–P04 em desktop e mobile.
6. Testar navegação somente por teclado e redução de movimento.
7. Validar todos os links externos publicados.
8. Publicar a pasta `dist` (build Vite) ou, em host estático simples, a árvore do projeto como está.
